# Support

Fretlane is a free, open-source hobby project made by one person. Help happens on GitHub, in public, so the answer can help the next person too.

## Before you ask

1. Check [FAQ and troubleshooting](FAQ-and-Troubleshooting). Most problems are covered there.
2. Make sure you have the [latest version](https://github.com/mauritsE/Fretlane/releases).
3. Search the [existing issues](https://github.com/mauritsE/Fretlane/issues?q=is%3Aissue) to see whether someone already reported it.

## Report a bug

Open a [new issue](https://github.com/mauritsE/Fretlane/issues/new) (you need a free GitHub account), or choose **Help → Report a Problem** in the app. Please include:

- your Fretlane version and where you got it (GitHub download, Mac App Store, or from source),
- your operating system and version (for example Windows 11, macOS 15, Ubuntu 24.04),
- what you did, what you expected, and what happened instead,
- for a tab that won't open or plays wrong: the file format, and the file itself if you're allowed to share it,
- for a sync problem: whether the song uses YouTube or Spotify, and the link.

Don't post personal information, your Spotify Client secret, or tabs you aren't allowed to share. Issues are public.

## Ask a question or suggest an idea

Open an issue too. Ideas and feature requests are welcome; say what you're trying to practise and what gets in the way.

## Mac App Store purchases

Refunds and billing for the Mac App Store version are handled by Apple. Request a refund at <https://reportaproblem.apple.com>. For problems with the app itself, open an issue as above.

## Security problems

If you find a security problem (for example, a way for a website to reach Fretlane's local server or read your files), please don't describe the details in a public issue. Open an issue that only says you found a security problem and would like a private way to report it, and you'll get one.

## Response time

Fretlane is maintained in spare time, so replies can take a few days. There is no paid support.

## Contribute

Fretlane is open source under the MIT License. Pull requests are welcome; for anything big, open an issue first to discuss it. The [README](https://github.com/mauritsE/Fretlane#development) explains how to run, test and build the app.

## Say thanks

If Fretlane helps you learn songs, you can [buy me a coffee on Ko-fi](https://ko-fi.com/mauritselzinga), or buy the Mac App Store version. Bug reports and ideas are just as welcome.
